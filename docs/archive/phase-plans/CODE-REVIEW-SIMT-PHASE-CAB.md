## ⚠️ 需要注意的问题

### 1. ptx_visiter.h 结构问题 (Minor)

**问题**: `#define X` 被重新定义

```cpp
// Line ~93-99 (问题代码)
#define X(enum_val, type_name, opstr, op_count, struct_kind, instr_kind) \

// Stage 2b: NEW - Warp-level synchronization
#define  VISITOR_DECL_WARP_BARRIER(opstr) \
    std::any visit##opstr##Inst(ptxparser::ptxParser::opstr##InstContext *pCtx) override;

#define X(enum_val, type_name, opstr, op_count, struct_kind, instr_kind) \
    VISITOR_DECL_##struct_kind(opstr)
#include "ptx_ir/ptx_op.def"
#undef X
```

**警告**:
```
warning: "X" redefined
```

**影响**: 不影响功能，但不符合最佳实践  
**建议修复**: 将 `VISITOR_DECL_WARP_BARRIER` 定义移到 X-macro 之前，避免重定义警告

**修复建议**:
```cpp
// 在第一个 #define X 之前添加
#define  VISITOR_DECL_WARP_BARRIER(opstr) \
    std::any visit##opstr##Inst(ptxparser::ptxParser::opstr##InstContext *pCtx) override;

// 然后正常的 X-macro 展开
#define X(enum_val, type_name, opstr, op_count, struct_kind, instr_kind) \
    VISITOR_DECL_##struct_kind(opstr)
#include "ptx_ir/ptx_op.def"
#undef X
```

**优先级**: 🟡 低（编译警告，不影响功能）
